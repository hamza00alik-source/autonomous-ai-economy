# MOBA HUD Vector Kit

Build the vector interface asset pack with the Python module and run the focused pytest test. The build creates 24 SVG icons, six SVG HUD panels, a README, SHA-256 manifest and ZIP archive. No paid dependency or network call is required. This pack is artwork only; no game logic, engine scripts, multiplayer HUD or PNG exports are included. Keep unpublished until licensing, marketplace eligibility, pricing and checkout are verified.
