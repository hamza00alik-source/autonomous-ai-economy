# MOBA HUD Vector Kit

Give a fantasy or MOBA prototype a consistent interface style with a compact set of original, editable vector assets.

## Included
- 24 ability, item and status icons: sword, shield, heart, mana, coin, potion, boots, bow, arrow, orb, crown, gem, skull, flag, hourglass, eye, bolt, target, portal, helmet, hammer, leaf, flame, rune and crystal
- 6 scalable HUD panels: bottom ability bar, health/mana panel, objective alert, match status, item shop card and scoreboard frame
- Individual SVG source files and a SHA-256 integrity manifest

## Compatibility
SVG assets can be imported into Godot 4, Unity, Unreal or web interfaces. Check scaling and import settings in your target engine.

## Scope
This is a vector art pack, not a working HUD, gameplay system or multiplayer interface. PNG exports and engine-specific scripts are not included. AI-assisted procedural vector generation.
