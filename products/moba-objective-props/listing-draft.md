## Short description

A compact set of five original, procedural low-poly fantasy objective and consumable props, supplied as individual GLB models with a Godot 4 demo project.

## Full description

Add a small set of fantasy gameplay objects to your prototype with MOBA Objective Props.

The pack contains five separate static 3D props:
- Mana Crystal
- Health Vial
- Rune Altar
- Supply Chest
- Ancient Coin Stack

Each model is supplied as a glTF 2.0 binary file (.glb). A combined preview model and a Godot 4 demo project are included so you can inspect the assets in an example scene.

### Included
- Five individual GLB models
- One combined preview GLB
- Godot 4 demo project and scene
- PBR material definitions
- README with setup and usage notes
- Draft license (final license text is still under review)

### Compatibility and verification
- File format: GLB / glTF 2.0
- Demo project: Godot 4
- Automated import and short headless launch check: Godot 4.7.2 in CI
- The included scene is provided as an inspection/demo starting point; adapt scale, placement and materials to your own project.

### Important limitations
These are static props, not complete playable characters or gameplay systems. The pack does not include rigging, animation, collision shapes, LODs, texture maps, Blender source files, Unity prefabs or Unreal assets. Visual appearance and target-project suitability should be inspected before use.
